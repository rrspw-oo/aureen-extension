# Icon Assets

This directory contains all icon assets for the Chrome extension and PWA support.

## Required Icons

The following icon files need to be created:

### Chrome Extension Icons
- `icon16.png` - 16x16px - Toolbar icon
- `icon48.png` - 48x48px - Extension management page
- `icon128.png` - 128x128px - Chrome Web Store

### PWA Icons
- `pwa-192x192.png` - 192x192px - Android small icon
- `pwa-512x512.png` - 512x512px - Android large icon
- `apple-touch-icon.png` - 180x180px - iOS home screen icon

### Web Icons
- `favicon.svg` - Scalable vector icon for browsers
- `favicon.ico` - 32x32 or 16x16 fallback icon

## Design Guidelines

### Color Scheme
- Primary: Emerald green (#059669)
- Secondary: Amber (#d97706)
- Background: White or transparent

### Icon Design
The icon should represent:
- Text highlighting concept
- Tagging/organization (hashtag symbol optional)
- Clean, minimal design
- High contrast for visibility

### Tool Recommendations
- Figma or Adobe Illustrator for vector design
- Export to PNG at exact pixel dimensions (no scaling)
- Optimize PNG files with tools like TinyPNG or ImageOptim
